=== PROYECTO ANDROID LISTO PARA ABRIR ===

1. Descomprime esta carpeta donde quieras tener el proyecto,
   por ejemplo:  C:\Users\Usuario\AndroidStudioProjects\EquiposFutbol

2. En Android Studio:  File -> Open  ->  selecciona la carpeta EquiposFutbol
   (la que contiene settings.gradle.kts, NO la de adentro)

3. Android Studio va a decir que faltan componentes del SDK.
   Dale a "Install missing SDK packages" y espera.
   Tambien va a descargar Gradle 8.9 la primera vez.

4. Si pide un JDK, elige el que trae Android Studio (JetBrains Runtime 17 o superior).

5. Para probar sin telefono:
   Tools -> Device Manager -> Create Virtual Device
   Pixel 4  ->  imagen de sistema API 30 o superior  ->  Finish
   Luego el triangulo verde.

6. Para generar el APK:
   Build -> Build Bundle(s)/APK(s) -> Build APK(s)
   Queda en  app/build/outputs/apk/debug/app-debug.apk
   Copialo a la raiz del proyecto antes de hacer git add
   (el .gitignore excluye la carpeta build).
